# ffc-new

Production target-independent driver and middle end for the Lazy Fortran
compiler program.

This repository will own the driver, target-independent analyses and
optimizations, and the `mir-v0` boundary consumed by `fortback-new`. The
laboratory repository at `../lazy-fortran-new` owns the roadmap, decisions,
experiments, runs, provenance manifests, and cross-repository wiring.

The repository starts with the `mir-v0` contract scaffold. It must remain
production-only: do not add research ledgers, experiment reports, model logs,
or copied external source material here.
